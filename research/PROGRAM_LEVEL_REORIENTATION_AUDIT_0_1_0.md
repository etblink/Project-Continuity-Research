## 5. Drift hypothesis

The program may be exhibiting a natural instance of the phenomenon it is trying to study:

```text
FACTS / EVIDENCE ABOUT PROGRAM STATE = largely correct
AUTHORITY BOUNDARIES = preserved
LOCAL TRANSITIONS = individually authorized
CCP-2 BOUNDARY = preserved
BUT
OPERATIONAL NEXT-ACTION PRIORITY = progressively captured by a subordinate research thread
```

The critical possible failure is not that an unauthorized experiment was run. The failure candidate is that a legitimate side inquiry became the de facto main trajectory without an explicit program-level decision that it superseded or deferred the Phase-4 human gate.

## 6. Strongest competing explanation

Before calling this confirmed semantic/purpose trajectory drift, test:

```text
PARALLEL-WORK / EXTERNAL-DEPENDENCY EXPLANATION
```

However, even under that explanation, the parallel work should have remained visibly subordinate to the Phase-4 exit gate and should have had an explicit effort/stop budget. The growing succession of local experiment gates made that hierarchy increasingly non-obvious.
