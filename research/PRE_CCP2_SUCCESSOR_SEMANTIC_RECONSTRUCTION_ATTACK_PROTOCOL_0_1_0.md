# Pre-CCP-2 Successor Semantic Reconstruction Attack Protocol 0.1.0

Date: 2026-09-20
Status: FROZEN RESEARCH PROTOCOL — NOT CCP-2 AUTHORIZATION
Governing docket: Issue #16

## Purpose

Test the narrow residual left after prior simplification attacks: whether a successor can receive complete, correctly governed project state and commitments yet reconstruct the operative meaning, scope, purpose, or uncertainty incorrectly enough to choose an unfaithful continuation.

This protocol is designed to kill the residual if ordinary retrieval, authority representation, handoff readiness, commitment-frontier state, structured context, or established grounding/common-ground mechanisms explain the effect.

## Research boundary

This is pre-CCP-2 research only.

It does not authorize:
- CCP-2 implementation;
- live-project mutation;
- modification of the frozen CCP-1 human cold-start target;
- T7, R16, or a new CCP component.

## Prior-art pressure

The experiment must treat the following as competing explanations rather than PCR novelty:

1. semantic handoff/readiness failure: a locally successful predecessor can leave a terminal state from which the successor cannot reliably begin;
2. commitment-frontier/residual-completion failure: accepted choices, realized effects, unfinished obligations, and evidence may be inadequately transferred;
3. structured execution-state failure: semantic retrieval alone may not reconstruct the active hierarchical task state;
4. common-ground/grounding failure: information availability is not equivalent to sufficient shared understanding for coordinated action.

## Core invariant controls

Across experimental conditions, hold constant:

- source corpus;
- factual content;
- retrievability;
- provenance;
- current/historical status;
- epistemic status;
- authority metadata;
- accepted commitments;
- realized effects;
- unfinished obligations;
- evidence links;
- locally valid next-action candidates.

A run is invalid for the semantic residual if its failure can be explained by missing or inaccessible information.

## Scenario construction

Construct at least three synthetic project states. Each must contain all of the following:

- a high-level purpose;
- a current bounded objective;
- at least one historical objective that is no longer operative;
- at least one accepted decision with rationale;
- at least one rejected alternative with a reopen condition;
- an unresolved uncertainty;
- a current authority boundary;
- an unfinished obligation;
- at least two locally plausible next actions;
- one next action that is factually and procedurally plausible but inconsistent with governing purpose, scope, or uncertainty;
- one next action faithful to the operative project model.

The discriminating pair must not differ merely by a hidden fact. The relevant distinction must be recoverable from the same supplied corpus.

## Conditions

### A — Complete corpus only

Successor receives the complete searchable corpus and the request to continue.

Purpose: establish the raw-availability baseline.

### B — Corpus + compact declarative orientation

Add a bounded orientation projection containing current objective, state, authority, uncertainty, and unfinished obligations.

Purpose: test whether ordinary compact orientation is sufficient.

### C — Corpus + structured state/commitment representation

Add explicit links among claims, authority, accepted decisions, evidence, effects, obligations, supersession, and current scope.

Purpose: control for structured execution-state and commitment-frontier explanations.

### D — C + explicit reconstruction/grounding step

Before proposing action, require the successor to externalize a project model containing:

1. what the project is for;
2. what is currently being attempted;
3. what is not currently authorized;
4. what is known, uncertain, superseded, or merely historical;
5. why the active commitments exist;
6. what unfinished obligations remain;
7. what facts or ambiguities require clarification;
8. the decision rule it will use to choose the next action.

The successor must then check that reconstruction against the supplied state before acting.

Purpose: test whether explicit grounding adds anything after state and commitments are already represented.

## Required outputs per run

Before seeing any reference answer, record:

- reconstructed purpose;
- reconstructed current objective;
- current authority boundary;
- current uncertainty;
- operative vs historical distinction;
- commitment rationale;
- unfinished obligations;
- proposed next action;
- rejected plausible alternative and reason;
- clarification request, if any;
- confidence for each major reconstruction claim.

## Measures

Score separately; do not collapse into one headline score before analysis.

1. factual reconstruction;
2. authority reconstruction;
3. epistemic/supersession reconstruction;
4. commitment reconstruction;
5. purpose/intent reconstruction;
6. next-action fidelity;
7. confidence calibration;
8. clarification calibration.

Also record whether a wrong next action occurred despite correct scores on measures 1–4.

## Semantic-residual discriminator

The strongest candidate positive case is:

```text
FACTS = correct
AUTHORITY = correct
EPISTEMIC_STATE = correct
COMMITMENTS = correct
NEXT_ACTION = materially unfaithful
CAUSE = wrong reconstruction of purpose/scope/meaning
```

A merely forgotten fact, missed file, wrong authority state, missing commitment, or unread evidence does not qualify.

## Ablation logic

Compare A→B, B→C, and C→D.

- If B removes the failure, compact orientation is sufficient for this scenario.
- If C removes it, structured state/commitment representation is sufficient.
- If D adds no reproducible benefit over C, do not invent an interactive grounding protocol.
- If D improves continuation, first attempt to explain the result as an application of established common-ground/grounding theory.
- Only a residual not reducible to those explanations may remain a PCR-specific research question.

## Kill / collapse criteria

Collapse the candidate residual if any of these holds:

1. failures disappear when retrieval/addressability is repaired;
2. failures disappear when authority or epistemic state is represented correctly;
3. failures disappear when accepted commitments and residual obligations are represented;
4. structured state representation performs equivalently to explicit grounding;
5. common-ground/grounding theory adequately explains any remaining D advantage;
6. purpose errors cannot be separated from missing or ambiguous source specification.

## Ambiguity safeguard

If two competent readers can derive materially different purposes from the same evidence without violating any stated constraint, classify the scenario as UNDER-SPECIFIED rather than as successor failure.

This is critical: the experiment must not punish a successor for ambiguity created by the originating project.

## Repetition / heterogeneity

A single model/run is exploratory only.

For stronger evidence, repeat across:
- multiple fresh contexts;
- at least two model families/providers when available;
- at least one unfamiliar human or human-mediated reconstruction only after doing so does not contaminate an already-frozen human trial.

Do not use the pending CCP-1 roommate trial as a participant in this experiment.

## Possible dispositions

Exactly one primary disposition should be chosen per scenario family:

- REDUCED_TO_RETRIEVAL
- REDUCED_TO_AUTHORITY_OR_EPISTEMIC_STATE
- REDUCED_TO_HANDOFF_READINESS
- REDUCED_TO_COMMITMENT_FRONTIER
- REDUCED_TO_STRUCTURED_STATE
- REDUCED_TO_COMMON_GROUND
- UNDER_SPECIFIED_SOURCE
- RESIDUAL_SEMANTIC_RECONSTRUCTION_CANDIDATE
- INCONCLUSIVE

## Advancement boundary

Even a residual candidate does not authorize architecture.

A positive result may justify a replication protocol or narrower requirement analysis. It does not by itself justify T7, R16, a new CCP component, or CCP-2.
