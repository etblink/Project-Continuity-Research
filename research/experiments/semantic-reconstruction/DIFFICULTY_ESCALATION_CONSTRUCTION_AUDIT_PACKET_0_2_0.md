1. this audit instruction; and

## Task

For each world D, E, and F, determine whether the corpus is suitable for a successor-continuity experiment.

Do not solve against a hidden answer key. Test whether the source itself supports a uniquely recoverable operative model **and requires genuine integration**.

For each world report the following.

### A. Reconstructed operative model

Without inventing facts, reconstruct:
1. governing purpose;
2. active workstreams/scopes;
3. current objective or unfinished obligation in each;
4. authority boundary by workstream/scope;
5. current vs historical/superseded state;
6. default rules;
7. authorized scoped exceptions;
8. closed/reopened alternatives and whether each trigger is satisfied;
9. unresolved uncertainties and exact scope;
10. next-action family satisfying all explicit constraints.

### B. Ambiguity attack

Try to construct two materially different next actions that both satisfy every explicit governing constraint.

- If successful: UNDER_SPECIFIED.
- If not: continue.

Do not treat ordinary implementation variants inside one substantive action family as under-specification.

### C. Hidden-preference attack

Determine whether choosing the operative continuation requires an unstated preference such as speed vs quality, conservatism vs progress, stakeholder importance, risk tolerance, aesthetics, or assumed organizational norms.

If yes: HIDDEN_PREFERENCE_DEPENDENCY.

### D. Missing-information attack

Identify any decision-relevant proposition required to distinguish faithful from unfaithful continuation that is absent.

If yes: MISSING_DECISION_FACT.

### E. Reading-trick attack

Determine whether the challenge is mainly obscure wording, arbitrary detail, or trick phrasing rather than integration across time/scope/authority.

If yes: READING_TRICK.

### F. Integration-burden check

Confirm whether success actually requires integrating:
- non-adjacent records;
- multiple supersession relations;
- simultaneous workstreams/scopes;
- scoped exceptions;
- distributed rationale;
- narrow uncertainty;
- salient recent evidence that is not itself decisive.

Do not count an element merely because it appears in the corpus; explain why earlier records are actually needed for the reconstructed continuation.

### G. Terminal-compression attack

Perform two explicit tests:

**G1 — Last-two-only test**
Pretend only the final two records of the world are available. Can you determine the substantive faithful continuation family with high confidence?

- If YES, mark TERMINAL_COMPRESSION_FAILURE.
- If NO, pass G1.

**G2 — Earlier-record ablation**
Identify at least three earlier non-adjacent records whose removal would materially impair reconstruction of purpose, authority, exception/reopen state, or workstream boundaries.

If you cannot identify them, mark INSUFFICIENT_INTEGRATION_DEPENDENCE.

### H. Shallow-heuristic attack

Test whether a successor could solve all three worlds using any single shallow rule without integrating the corpus, including:
- latest record wins;
- always choose the conservative option;
- always reject stakeholder requests;
- always keep workstreams separate;
- never reopen a closed proposal;
- prefer explicit recent metrics.

At least one world should defeat "always conservative / never reopen" through a legitimately satisfied reopen condition.

If one shallow heuristic solves all three, mark SHALLOW_HEURISTIC_DEFECT.

### I. Peripheral-latitude check

Identify optional or underspecified side choices.

Distinguish:
- harmless latitude within the same continuation family;
- latitude that would contaminate scoring of the core next action.

If the latter remains, mark OTHER_DESIGN_DEFECT.

### J. Final disposition

Choose exactly one per world:

- UNIQUE_ENOUGH_FOR_EXPERIMENT
- UNDER_SPECIFIED
- HIDDEN_PREFERENCE_DEPENDENCY
- MISSING_DECISION_FACT
- READING_TRICK
- TERMINAL_COMPRESSION_FAILURE
- INSUFFICIENT_INTEGRATION_DEPENDENCE
- SHALLOW_HEURISTIC_DEFECT
- OTHER_DESIGN_DEFECT

If any world does not receive UNIQUE_ENOUGH_FOR_EXPERIMENT, give the minimum repair.
