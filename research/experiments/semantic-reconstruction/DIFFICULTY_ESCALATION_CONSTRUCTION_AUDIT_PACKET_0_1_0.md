# Difficulty-Escalation World Construction Audit Packet 0.1.0

Date: 2026-09-21
Status: FROZEN AUDITOR INSTRUCTION — INDEPENDENT REVIEW REQUIRED
Governing docket: Issue #16

## Auditor isolation requirement

The auditor must be a fresh context that has not seen:

- the reference/adjudication key;
- intended correct next actions;
- prior successor answers;
- the first experiment's adjudication beyond the fact that it ceilinged;
- any designer commentary explaining the intended traps.

The auditor receives only:
1. this audit instruction; and
2. `DIFFICULTY_ESCALATION_WORLDS_0_1_0.md`.

## Task

For each synthetic world D, E, and F, independently determine whether the source corpus is suitable for a successor-continuity experiment.

Do **not** solve against a hidden answer key. Instead test whether the corpus itself supports a uniquely recoverable operative project model.

For each world report:

### A. Reconstructed operative model

Without inventing facts, reconstruct:

1. governing purpose;
2. active workstreams;
3. current objective of each workstream;
4. authority boundary by workstream;
5. current vs historical/superseded state;
6. default rules;
7. authorized scoped exceptions;
8. closed/reopenable alternatives;
9. unresolved uncertainties and exact scope;
10. unfinished obligations;
11. the next-action family that satisfies all explicit constraints.

### B. Ambiguity attack

Try to construct **two materially different next actions** that both satisfy every explicit governing constraint.

- If you can, quote the source support for both and mark the world `UNDER_SPECIFIED`.
- If you cannot, mark `UNIQUE_ENOUGH_FOR_EXPERIMENT`.

Do not call ordinary implementation freedom under-specified if the alternatives belong to the same substantive continuation family.

### C. Hidden-preference attack

Ask whether choosing the continuation requires any unstated preference such as:

- speed vs quality;
- conservatism vs progress;
- stakeholder importance;
- risk tolerance;
- aesthetic preference;
- assumed organizational norm.

If an unstated preference is necessary to decide, mark `HIDDEN_PREFERENCE_DEPENDENCY`.

### D. Missing-information attack

Identify any decision-relevant proposition that must be known to distinguish faithful from unfaithful continuation but is absent from the corpus.

If one exists, mark `MISSING_DECISION_FACT`.

### E. Mere-reading-comprehension attack

Assess whether the difficulty arises only from obscure wording, trick phrasing, or arbitrary detail rather than integration across time/scope/authority.

If so, mark `READING_TRICK`.

### F. Integration-burden check

Confirm whether the world actually requires integration of at least:

- non-adjacent records;
- multiple supersession relations;
- simultaneous workstreams;
- scoped exceptions;
- distributed rationale;
- narrow uncertainty;
- salient but non-authoritative recent evidence.

### G. Final audit disposition

Choose exactly one:

- `UNIQUE_ENOUGH_FOR_EXPERIMENT`
- `UNDER_SPECIFIED`
- `HIDDEN_PREFERENCE_DEPENDENCY`
- `MISSING_DECISION_FACT`
- `READING_TRICK`
- `OTHER_DESIGN_DEFECT`

If any world does not receive `UNIQUE_ENOUGH_FOR_EXPERIMENT`, explain the minimum repair needed.

## Contamination rule

Do not search the repository for related experiment files. Do not request or infer the reference key. Do not use external web sources.

The audit should stand entirely on the supplied world corpus.
