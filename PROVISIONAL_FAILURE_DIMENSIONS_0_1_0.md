# Provisional Failure Dimensions — 0.1.0

Status: **Coding aid only. Not a taxonomy.**

These labels emerged during the first incident reconstruction pass. They are intentionally overlapping and may later merge, split, or disappear.

- `STALE_STATE` — a representation remains influential after reality has advanced.
- `AUTHORITY_CONFUSION` — the system cannot correctly determine which artifact or rule governs.
- `SEMANTIC_DRIFT` — wording/meaning moves away from current project identity or doctrine.
- `EVIDENCE_STATE_CONFLATION` — observed evidence is mistaken for committed/canonical state.
- `MACHINE_PASS_OVERREACH` — automated success is treated as broader acceptance than the gate proves.
- `QUALIFICATION_CONFLATION` — distinct acceptance layers collapse into one another.
- `CONTRACT_DRIFT` — a frozen/literal interface is optimized away or reinterpreted.
- `LOCAL_CAUSE_BIAS` — the nearest visible failure is assumed to originate locally.
- `PREMATURE_REPAIR` — implementation changes begin before causal localization is sufficient.
- `SUCCESSION` — predecessor/successor state transmission is incomplete, stale, or falsely trusted.
- `TEMPORAL_AUTHORITY` — an artifact's authority changes with time but that validity window is implicit.
- `PURPOSE_DRIFT` — local work ceases to serve the project's larger purpose.
- `ANCESTRY_BIAS` — inherited implementation structure becomes an unearned design constraint.
- `LOCAL_OPTIMIZATION` — a bounded metric/task is optimized at the expense of the larger system.
- `GOODHART_PRESSURE` — a measurable proxy begins replacing the broader objective it was meant to indicate.
- `ORIENTATION_OVERHEAD` — context reconstruction grows beyond what is required for safe progress.
- `ANALYSIS_PARALYSIS` — additional reasoning continues after the action threshold has already been met.
- `CAPABILITY_BOUNDARY_CONFUSION` — local UI/product control is mistaken for control over an external system.
- `ROUTING_DRIFT` — stale navigation/next-step language directs work incorrectly.
- `METHOD_DRIFT` — stated methodological law no longer matches canonical practice or cases.
- `ABSTRACTION_MISMATCH` — a generalization fails against its own accepted examples.
- `PROMOTION_OVERREACH` — evidence for one layer is used to justify an unauthorized higher-level transition.
- `DESIRE_EVIDENCE_CONTAMINATION` — hoped-for success affects interpretation of what evidence establishes.
- `RETENTION_AUTHORITY_CONFLATION` — preservation for history is confused with permission to govern current work.
- `CLEANUP_SEMANTIC_DAMAGE` — cleanup removes or alters material whose evidentiary/governance significance was not understood.
- `OTHER` — mandatory escape hatch for incidents that do not fit the current coding frame.

## Warning

This file exists to make early coding consistent enough to compare incidents. It must not become a semantic trap. The research charter explicitly requires that evidence be allowed to reveal new dimensions or invalidate the current ones.
